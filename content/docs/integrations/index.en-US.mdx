Every third party the application talks to lives in `src/integrations/<vendor>/`, and every file in such a folder is named `<vendor>.<concern>.ts`. A folder holds configuration, the vendor client, request-time adapters and the Zod schemas that describe the vendor's payloads — nothing else. Business rules and database access belong in `src/modules/{feature}/`, and components in `src/presentation/` never construct a vendor client themselves.

The formatter enforces this separation at the import level: `vite.config.ts` defines an `integrations` import group for `~/src/integrations/**` that always sorts above `modules`, `lib` and the component groups, so a file that reaches for a vendor is visible at a glance.

TanStack Start, TanStack Router and TanStack Query have no adapter folder of their own beyond `query.invalidation.ts` and `query.sync.ts`, because they are the application framework rather than a vendor behind a seam. Their configuration lives in `src/router.tsx`, `src/server.ts` and `vite.config.ts`; the [TanStack Start](/docs/integrations/tanstack-start) and [TanStack Query](/docs/integrations/tanstack-query) pages document those files.

## Conventions

A file ending in `.server.ts` or `.server.tsx` is never imported from a component; it is reached either from a server function's handler or from a Worker handler. `src/integrations/drizzle-orm/drizzle.database.ts` and `src/lib/background.ts` additionally open with `import "@tanstack/react-start/server-only"`, which makes a client import a build error rather than a runtime surprise.

Secrets are read through `env` from `cloudflare:workers`, never from `process.env`, and only in server files:

```ts
import { env } from "cloudflare:workers"

import StripeServer from "stripe"

export const stripe = new StripeServer(env.STRIPE_SECRET_KEY, {
  apiVersion: STRIPE_API_VERSION,
  appInfo: { name: APP_NAME },
  httpClient: StripeServer.createFetchHttpClient(),
})
```

Browser-visible configuration uses `import.meta.env.VITE_*` instead — `VITE_STRIPE_PUBLISHABLE_KEY` in `stripe.client.ts` and `VITE_R2_URL` in `src/lib/url.ts`. The required secrets per environment are listed in `wrangler.jsonc` under `env.<name>.secrets.required`.

Each folder has a sibling `__test__/` directory; there are 53 test files across `src/integrations/`, run by `bun run test`. Tests named `*.component.test.ts(x)` run in the jsdom project and `*.integration.test.ts` in the integration project — see [Tooling](/docs/tooling).
