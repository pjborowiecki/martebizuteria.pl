M'Arte to jedna aplikacja TanStack Start, która z pojedynczego Workera Cloudflare obsługuje sklep, panel klienta, panel administracyjny i tę dokumentację. Wszystko, czego aplikacja potrzebuje w czasie działania, to bindingi Cloudflare: D1 na dane, R2 na zdjęcia produktów, KV jako pamięć podręczna, kolejka na dziennik audytu oraz Durable Object do unieważniania pamięci podręcznej w czasie rzeczywistym.

Ma to jedną konsekwencję, o której warto wiedzieć przed rozpoczęciem pracy: **nie ma w pełni offline'owego trybu pracy**. `bun run dev` ustawia `CLOUDFLARE_ENV=development`, a `vite.config.ts` włącza zdalne bindingi wtyczki Cloudflare dokładnie dla tej wartości:

```ts
...cloudflare({
  inspectorPort: false,
  remoteBindings: process.env["CLOUDFLARE_ENV"] === "development",
  viteEnvironment: { name: "ssr" },
}),
```

Serwer deweloperski rozmawia więc z prawdziwą bazą D1 środowiska preview, z prawdziwym zasobnikiem R2 `martebizuteria` i z prawdziwą przestrzenią nazw KV. Środowiska `development` i `preview` w `wrangler.jsonc` deklarują ten sam `database_id` i ten sam zasobnik, co oznacza, że **zapisy wykonane w trybie deweloperskim trafiają do bazy preview**. Traktuj ją jak bazę współdzieloną, nie jak brudnopis.

Drugi sposób uruchomienia aplikacji to `bun run start`, który serwuje gotowy build z `CLOUDFLARE_ENV=preview`. Skoro ta wartość nie jest równa `development`, zdalne bindingi są wyłączone i używane są lokalne, symulowane D1, R2 i KV z katalogu `.wrangler/state/`. To najbliższa dostępna wersja odizolowanego uruchomienia lokalnego — startuje jednak z pustą bazą danych.

## Najkrótsza wersja

Jeśli masz już CLI `vp`, konto Cloudflare z przygotowanymi bindingami i dane uwierzytelniające pod ręką:

```sh
git clone https://github.com/pjborowiecki/martebizuteria.pl.git
cd martebizuteria.pl
vp install
cp .env.example .env.development   # następnie wpisz prawdziwe wartości
bunx wrangler login
bun run db:migrate:development
bun run dev
```

Sklep jest wtedy pod adresem `http://localhost:3000` po polsku i `http://localhost:3000/en-US` po angielsku. `pl-PL` to lokalizacja domyślna i nie ma prefiksu w adresie URL.
